# skill-seed 使い方手順書

## はじめに

### skill-seed とは

Claude に「仕事のやり方」を覚えさせる仕組みを **SKILL** と呼びます。SKILL は手順やルールを書いたファイルのまとまり（フォルダ）で、一度入れておくと、Claude は依頼の内容に応じて自動でそれを使います。

**skill-seed** は、この SKILL を作るための SKILL です。流れは次のとおりです。

1. 作りたい SKILL の要件を、Excel の「ヒアリングシート」に書いてもらう
2. Claude がシートを読み、記入漏れをチェックする
3. Claude が SKILL 作成用の指示文（プロンプト）を作り、人の承認を待つ
4. 承認後、Anthropic 公式の SKILL 作成ツール **skill-creator** で SKILL を生成する

チャットで要件を聞き取りながら作ると、聞き漏れや、Claude が勝手に推測で補う部分が出やすくなります。skill-seed は聞き取りを事前にシートで済ませ、**シートに書かれていないことは推測で補わない**ように作られています。

### 登場人物

| 役割 | やること | 読む章 |
|---|---|---|
| 実行者 | skill-seed を導入し、テンプレートを配り、記入済みシートから SKILL を作る | 1, 2, 4, 5 |
| 記入者 | ヒアリングシートに要件を書く（IT に詳しくなくても書けるようにしてあります） | 3, 5 |

1人が両方を兼ねても構いません。

### 全体の流れ

1. 実行者が skill-seed を導入する（最初の1回だけ）
2. 実行者が Claude に頼んで空のテンプレートをもらい、記入者に渡す
3. 記入者がシートを書き、必要なファイルを添えて実行者に返す
4. 実行者が記入済みシートを Claude に渡す
   - 記入漏れがあれば、Claude は不足の一覧を返して止まる。記入者に直してもらい、4 からやり直す
5. Claude が作ったプロンプトを実行者が確認し、承認する
6. Claude が skill-creator で SKILL を生成する

## 1. 導入する（実行者）

### 1.1 配布物

| ファイル | 内容 |
|---|---|
| `skill-seed.zip` | SKILL 本体。中に `skill-seed` フォルダが1つ入っています |
| `手順書.md` | この手順書 |

zip の中身は次のとおりです。中のファイルを直接編集する必要はありません。

```
skill-seed/
├── SKILL.md                         … Claude が読む手順書（本体）
├── assets/
│   └── skill-seed_hearing_sheet.xlsx … 配布用の空テンプレート
├── scripts/                         … シートの読み込み・テンプレート生成用の Python スクリプト
└── references/                      … 質問の定義、プロンプトの組み立てルール
```

skill-seed は **Claude.ai・アプリ** と **Claude Code** のどちらでも使えます。使う方の手順で導入してください。

### 1.2 Claude.ai・アプリで使う場合

前提:
- 設定で「コード実行とファイル作成」がオンになっていること（SKILL はこの機能を使って動きます）

手順:
1. Claude.ai を開き、**プラグイン > 追加 > プラグインをアップロード** に進む
2. `skill-seed.zip` を**解凍せずに**そのままアップロードする
3. **プラグイン > Skills（タブ） > すべて表示** に skill-seed が表示されていれば導入完了

アップロードした SKILL は自分のアカウントだけで使えます。他の人にも使ってもらう場合は、その人にも同じ手順で入れてもらってください（Team・Enterprise プランでは共有機能もあります）。

### 1.3 Claude Code で使う場合

前提:
- Python 3 が入っていること
- Python ライブラリ `openpyxl` が入っていること（入っていなければ、実行時に Claude が `pip install openpyxl` を行います）

手順:
1. `skill-seed.zip` を解凍する
2. 出てきた `skill-seed` フォルダを、次のどちらかに置く
   - 自分のすべてのプロジェクトで使う場合: `~/.claude/skills/`
   - 特定のプロジェクトだけで使う場合: `<プロジェクト>/.claude/skills/`
3. 配置後、`~/.claude/skills/skill-seed/SKILL.md` のように、`SKILL.md` が `skill-seed` フォルダの直下にあることを確認する
4. Claude Code を起動し直し、`/skills` で一覧に skill-seed が出ることを確認する

### 1.4 skill-creator を使えるようにする

skill-seed は最後の工程で skill-creator を呼び出します。

- Claude.ai・アプリ: **プラグイン > Skills（タブ） > すべて表示** に skill-creator が表示されているか確認してください。
- Claude Code: skill-creator を導入しておいてください。

skill-creator が使えない環境でも、skill-seed は止まらずに「skill-creator 用プロンプト」のファイルを渡してくれます。そのファイルを、skill-creator が使える環境の Claude に渡せば続きを作れます。

## 2. テンプレートを入手して配る（実行者）

Claude に次のように頼みます。

> skill-seed のヒアリングシートをください

Claude.ai・アプリならダウンロードできる形で、Claude Code ならカレントディレクトリに `skill-seed_hearing_sheet.xlsx` が出力されます。これを記入者に渡してください。

## 3. シートを記入する（記入者）

### 3.1 基本のルール

- **黄色のセルだけに書きます。** それ以外のセルは編集できないよう保護されています。
- 項目には次の区分があります。

| 区分 | 意味 |
|---|---|
| ★必須 | 必ず書きます。空欄があると、Claude は作業を始めずに不足の一覧を返します |
| ★条件付 | 前の質問の答えによって必須になります（例: H-01 で「はい」なら H-02 が必須） |
| 推奨 | 書くと SKILL の精度が上がります。空欄でも作業は進みます |
| 任意 | 分かる範囲で構いません |

- 灰色の「例」の行は書き方の見本です。消したり書き換えたりする必要はありません（読み込み時は無視されます）。
- ▼が出るセルはプルダウンです。リストから選ぶか、「その他」の代わりに直接入力もできます（警告が出たら「はい」を押してください）。
- 表は上の行から詰めて、1行に1件ずつ書きます。
- セル内の改行は、Windows は **Alt + Enter**、Mac は **Option + Return** です。
- 最初の「0_記入ガイド」シートにも同じ説明があります。

### 3.2 シートごとの書き方

各シートの D 列（回答欄）に書きます。「説明・ヒント」列も参考にしてください。

#### A. 基本情報 ― どんなSKILLを作りたいか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| A-01 | このSKILLの呼び名（日本語） | ★必須 | 社内で呼ぶ名前で構いません |
| A-02 | 英語名 | 任意 | 半角英小文字とハイフンのみ（例: `meeting-minutes`）。空欄なら Claude が提案します |
| A-03 | 何ができるようになってほしいか | ★必須 | 「〇〇から△△を作る」のように、入力と出来上がりが分かるように1〜2文で |
| A-04 | なぜ必要か・今の困りごと | ★必須 | 時間がかかる、品質がバラバラ、など |
| A-05 | 主に使う人 | ★必須 | 自分のみ／チーム／部署全体／全社／その他 |
| A-06 | 使う人のITへの慣れ | 任意 | SKILL の説明の丁寧さを決めるのに使います |
| A-07 | どこで使うか | ★必須 | ブラウザやアプリでチャットするなら「Claude.ai・アプリ」 |
| A-08 | 使う頻度 | 任意 | |
| A-09 | 記入者のお名前 | 任意 | 確認したいときの連絡先 |
| A-10 | 記入日 | 任意 | |

#### B. 使う場面 ― どう頼まれたら、このSKILLを使うか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| B-01 | このSKILLを使ってほしい依頼文の例 | ★必須（3件以上） | 実際に話しかける言葉そのままで、1行に1つ。言い方を変えたものが多いほど精度が上がります。3つ思いつかなければ「○○（呼び名）を使って〜」も1行として書いて構いません。最大10行 |
| B-02 | よく出てきそうなキーワード | 任意 | 読点（、）区切り |
| B-03 | 似ているけれど、使ってほしくない場面 | 推奨 | B-01 と似ていて Claude が取り違えそうな頼み方。理由も書けると正確になります |
| B-04 | 役割が重なりそうな既存のSKILL | 任意 | 分からなければ空欄で構いません |

B-01 と B-03 は、Claude が「この依頼でこの SKILL を使うかどうか」を判断する材料になります。SKILL の使われやすさに直結するので、なるべく具体的に書いてください。

#### C. 入力 ― Claudeに何を渡すか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| C-01 | SKILL を使うときに渡すもの | ★必須（1件以上） | 1行に1つ。最大8行。下の列を埋めます |

C-01 の列: 入力の名前、種類（チャットの文章／ファイル／URL／その他）、ファイル形式、毎回あるか、中身の説明、サンプル（添付する／後で用意／なし）、添付ファイル名。

サンプルを「添付する」にしたら、**添付ファイル名を必ず書き**、そのファイルを Excel と一緒に渡してください（5章の注意も参照）。

#### D. 作業手順 ― 人がやるなら、どんな順番で何をするか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| D-01 | 手順の順番をどこまで守るか | ★必須 | 必ずこの順番／ある程度自由／おまかせ |
| D-02 | 作業の手順 | ★必須（2件以上） | 普段手作業でやっている順番で、できるだけ小さく分けて1行に1ステップ。最大15行 |

D-02 の列: やること、判断のポイント・注意点、使う道具・情報、人の確認が必要か。「判断のポイント」に迷いどころやコツを書くと精度が上がります。「人の確認が必要？」を「はい」にした手順では、作られる SKILL が利用者に確認してから先に進むようになります。

#### E. 出力 ― 何ができあがれば完成か

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| E-01 | 出力の形式 | ★必須 | チャットの文章／Word／Excel／PowerPoint／PDF／Markdown／その他 |
| E-02 | 出力の構成（見出しや項目の並び） | ★条件付 | セル内で改行して上から順に。**E-06 を書いて添付するなら空欄で構いません**（E-06 が空欄なら必須） |
| E-03 | 文体 | 任意 | |
| E-04 | 分量の目安 | 任意 | ページ数、文字数など |
| E-05 | ファイル名のルール | 任意 | ファイルで出力する場合のみ |
| E-06 | 理想の出力例（添付するファイル名） | 推奨 | 過去にうまく作れた例があれば、ファイル名を書いて一緒に渡します |
| E-07 | 何ができていれば「合格」か | ★必須 | 出来上がりをチェックするときに見るポイント |

#### F. ルール ― 必ず守ること・やってはいけないこと

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| F-01 | ルール | 推奨 | 種類（必ず守る／絶対にやらない／できればやる）、内容、理由。最大10行。ファイルの削除や外部への送信など、Claude にさせたくない操作は「絶対にやらない」として書きます |
| F-02 | 社内用語・略語の説明 | 任意 | Claude が知らない社内用語があれば |

理由も書いておくと、Claude が想定外の場面でも正しく判断しやすくなります。

#### G. 例外 ― 困ったときにどうしてほしいか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| G-01 | 判断に迷ったときの基本方針 | ★必須 | 必ず質問する／推測で進めてその旨を書く／作業を止める |
| G-02 | こんなときは、こうしてほしい | 推奨 | 入力が足りない、想定外の形式だった、などの場面と対応 |

#### H. テスト ― 出来上がったSKILLの品質をどう確かめるか

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| H-01 | テストで品質を確かめたいか | ★必須 | はい／いいえ／おまかせ |
| H-02 | テストケース | ★条件付（H-01 が「はい」なら2件以上） | 実際にありそうな依頼文、添付ファイル名、期待する結果、確認ポイント。最大8行 |

#### I. 参考資料・外部サービス・機密情報

| ID | 項目 | 区分 | ポイント |
|---|---|---|---|
| I-01 | 参考資料 | 任意 | 資料名、添付ファイル名または保存場所、使い方（読んで参考にする／ひな形として使う／SKILLに同梱する） |
| I-02 | 使う外部サービス | 任意 | Slack、Google Drive、Notion、社内システムなど。なければ「なし」 |
| I-03 | 個人情報や社外秘の情報を扱うか | ★必須 | はい／いいえ／分からない |
| I-04 | どんな情報で、どう扱うべきか | ★条件付（I-03 が「はい」なら必須） | 例: 社外への送信禁止、出力にフルネームを載せない |

### 3.3 記入が終わったら

シートに書いたファイル名（C-01、E-06、H-02、I-01 の添付ファイル）と同じ名前のファイルを用意し、**Excel と一緒に**実行者へ渡してください。シートに名前があるのにファイルがないと、作業が止まります。

## 4. 記入済みシートから SKILL を作る（実行者）

### 4.1 シートを渡す

**Claude.ai・アプリ**: 記入済みの Excel と添付ファイルを**すべて**チャットに添付し、次のように頼みます。

> skill-seed で、このヒアリングシートから SKILL を作って

**Claude Code**: ファイルの場所をパスで伝えます。

> skill-seed で ./input/記入済み.xlsx から SKILL を作って。添付は ./input/sample_transcript.txt と ./input/good_example.docx

どちらの場合も、Claude が自動でシートを読み込み、必須項目と添付ファイルをチェックします。Python スクリプトを自分で実行する必要はありません。

### 4.2 チェック結果ごとの対応

| 結果 | Claude の動き | 実行者がやること |
|---|---|---|
| 読み込めない（error） | 理由を伝えて止まる | skill-seed のテンプレートではない、またはシートや行が消されています。最新のテンプレートで書き直してもらう |
| 不足あり（incomplete） | 不足項目と見つからない添付ファイルの一覧を返して止まる | 一覧はそのまま記入者に転送できる文面になっています。記入者に直してもらい、4.1 からやり直す。添付ファイルの不足は「ファイルを追加で渡す」か「シートからファイル名を消す」のどちらでも解消できます |
| 問題なし（ok） | 次の工程に進む | 4.3 へ |

推奨項目の空欄やテンプレートの版違いでは止まりません。これらは次の確認の場面でまとめて表示されます。

### 4.3 プロンプトを確認して承認する

Claude はシートの内容から skill-creator 用の指示文を作り、`skill-creator_prompt.md` として保存したうえで、**必ず一度止まって承認を求めます**。

確認するポイント:
- シートの内容が正しく反映されているか
- 「（未記入）」の箇所。このまま進めると、skill-creator がその点を質問してきます
- 警告の一覧（推奨項目の空欄、版違いなど）

修正があればチャットで伝えると、プロンプトを直して再度確認を求めてきます。シートの内容と矛盾する修正をした場合は、どちらを正とするかを聞かれます。

問題なければ「この内容で進めて」などと伝えて承認します。

### 4.4 SKILL の生成

承認後、Claude が skill-creator を使って SKILL を作ります。途中で skill-creator から質問が出ることがあります。シートに答えがある質問は Claude が自分で答え、ない質問はあなたに聞いてきます。テストを希望した場合（H-01）は、テストと改善も行われます。

### 4.5 できあがるもの

出力先（Claude.ai・アプリではダウンロード、Claude Code ではカレントディレクトリ）に、次のものができます。

```
<SKILLの英語名>-seed/
├── attachments/              … 渡された添付ファイルのコピー
└── skill-creator_prompt.md   … 元の要件（後で SKILL を直すときに使えます）
```

あわせて、生成された SKILL のフォルダも出力されます。この SKILL を使うには、1章と同じ手順で導入してください（Claude.ai・アプリでは zip にしてアップロード、Claude Code では `skills` フォルダに配置）。

`skill-creator_prompt.md` は捨てずに残しておくことをおすすめします。SKILL を手直しするとき、元の要件として使えます。

## 5. 既知の問題と注意点

現在の版（テンプレート 1.1）には、次の既知の問題があります。修正するまでは、下の回避方法で対応してください。

### 記入者向け

| 問題 | 回避方法 |
|---|---|
| 添付ファイル名に**空白**が入っていると、ファイルの有無がチェックされない | ファイル名に空白を使わない（`_` や `-` に置き換える） |
| Mac で付けた日本語のファイル名（特に濁点・半濁点を含むもの）が、添付していても「見つからない」と判定されることがある | 添付ファイル名は半角英数字にする |
| C-01 でサンプルを「添付する」にしても、ファイル名が空欄だと指摘されない | 「添付する」にしたら、必ずファイル名を書く |
| 表の行が足りないときの「（続きは別紙）」が、現状では読み込まれない。シートが保護されているため行も追加できない | なるべく決められた行数に収める。収まらない場合は実行者に伝え、4.3 の確認時に補ってもらう |
| H-01 を「いいえ」にしても、H-02 に書きかけの行が残っていると不足として止まる | H-01 を「いいえ」にしたら、H-02 は空にする |
| 表のセルに改行や `\|` が入っていると、プロンプト内の表が崩れる | 表のセルでは改行と `\|` を使わない（E-02 などの表以外のセルの改行は問題ありません） |
| A-02（英語名）の形式がチェックされない | 半角英小文字とハイフンだけで書く。分からなければ空欄にする |

### 実行者向け

| 問題 | 回避方法 |
|---|---|
| 古い版のテンプレートで書かれたシートで、新しく追加された質問の行がないと「行が削除された可能性」と表示される | 実際には版の違いが原因です。最新のテンプレートで書き直してもらう |
| I-03（機密情報）が「はい」でも、添付ファイルが生成された SKILL に同梱されることがある | 4.3 と 4.4 で、機密情報を含むファイルが SKILL に入っていないか確認する |
| ★必須項目に「分からない」と書くと、チェックを通過する | 4.3 で「分からない」が残っていないか確認し、必要なら記入者に確認する |
| 「SKILLを作りたい」と頼むと、skill-seed ではなく skill-creator が使われることがある | 頼むときに「skill-seed で」と名前を入れる |
| A-02 が空欄のとき、作業フォルダ名（英語名の候補）がどう決まるかが一定しない | 気になる場合は、A-02 に英語名を書いてもらう |

## 困ったとき

- **skill-seed が使われない**: Claude.ai・アプリでは、**プラグイン > Skills（タブ） > すべて表示** に skill-seed が表示されているかを確認します。依頼文に「skill-seed で」と入れると確実です。
- **zip のアップロードに失敗する**: zip を解凍・再圧縮していないか確認します。zip の直下に `skill-seed` フォルダがあり、その中に `SKILL.md` がある構成が必要です。
- **Claude Code で Python のエラーが出る**: Python 3 と `openpyxl` が入っているか確認します。
